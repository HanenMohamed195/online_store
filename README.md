# online_store
  Online Store Database – E‑Commerce Relational Database Design & Implementation

##  Project Overview

This project was developed as part of the "Database Systems*"course at "Alexandria University, Faculty of Computers and Data Science" (Fall 2025/2026).

We designed and implemented a fully functional "relational database for an online store", supporting core e‑commerce operations:
- Customer registration & profile management  
- Product browsing by category  
- Shopping cart (add/remove items)  
- Order placement & payment processing  
- Order status tracking (Pending, Shipped, Delivered)  
- Admin inventory & category management  


##  Tools & Technologies

- "SQL (MySQL dialect)" – DDL, DML, queries  
- "ER/EER Modeling" – Conceptual & logical design  
- "Data Dictionary" – Detailed attribute definitions
